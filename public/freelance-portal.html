Syarat & Ketentuan Kemitraan

Harap baca dan setujui kesepakatan kemitraan berikut sebelum mengakses portal freelance Anda:

KESEPAKATAN KEMITRAAN PARTNER FOTOGRAFER / VIDEOGRAFER

1. Standar Layanan & Profesionalisme

Freelancer setuju untuk menjaga kualitas standar terbaik, hadir di lokasi minimal 15 menit sebelum waktu pemotretan dimulai, menggunakan pakaian rapi dan sopan (kemeja/kaos berkerah hitam/gelap), serta berinteraksi secara sopan & ramah kepada klien.

2. Pengiriman File & Batas Waktu (Deadline)

Freelancer wajib mengunggah seluruh hasil foto mentah (RAW) atau file editing (sesuai paket) ke link pengerjaan/Google Drive yang ditugaskan maksimal dalam waktu 24 jam setelah pemotretan selesai. Keterlambatan pengiriman file dapat mempengaruhi evaluasi performa & potongan fee kemitraan.

3. Hak Cipta & Kerahasiaan Data

Seluruh hak milik media foto/video adalah milik agensi dan klien. Freelancer dilarang menyebarkan, mempublikasikan di media sosial pribadi, atau menggunakan hasil karya sesi klien untuk kepentingan portofolio komersil pribadi tanpa izin tertulis dari agensi.

4. Skema Payout & Penggajian

Fee kerja freelance dihitung berdasarkan tarif per-sesi/per-jam yang disepakati. Pembayaran payout akan ditransfer langsung ke rekening terdaftar setelah hasil foto melewati proses Quality Control (QC) oleh admin dan pelunasan pembayaran telah diselesaikan oleh klien.

5. Masa Percobaan (Probation Status)

Sebagai partner baru, Freelancer menyetujui masa evaluasi (probation) selama 3 sesi pemotretan pertama. Evaluasi mencakup kedisiplinan waktu kehadiran, kerapian hasil foto, serta kelengkapan setor berkas digital.

Setor File Pemotretan

📋 SOP & KETENTUAN PENGIRIMAN FILE:

  • Format Kamera: Wajib gunakan Dual-Save: RAW (Kualitas Terbaik) + JPG (Kualitas Terendah / Small / Basic).
  • Kurasi di Kamera: Hapus foto yang gagal (blur, miss-focus, mata tertutup) langsung di kamera Anda demi menyeleksi hasil terbaik sejak awal.
  • Folder JPG Seleksi: Hanya berisi file JPG Original kualitas rendah hasil kurasi (RAW dilarang masuk folder ini).
  • Struktur Drive: Buat folder utama `[BKG-ID] - Nama Client`. Di dalamnya buat subfolder `/1. All File JPG` (tempel link ini di input JPG) dan `/2. RAW` (jika luar kota).
🖼️ File JPG (Untuk Galeri Seleksi)
Silakan serahkan kartu memori / flashdisk berisi file JPG Anda langsung ke kantor Admin.
