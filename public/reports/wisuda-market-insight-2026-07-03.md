## 2. Musim Wisuda Makassar

Wisuda tersebar **hampir sepanjang tahun** karena setiap universitas punya jadwal sendiri.

| Bulan | Kampus yang Biasanya Wisuda |
|---|---|
| **Februari** | UNM, Unhas, UIN, UMI |
| **April** | Unibos, UNM, beberapa PTS |
| **Mei** | UNM, Unhas |
| **Juni** | UMI, Unhas, UNM, banyak PTS |
| **September** | UNM, UIN, PTS besar |
| **November** | UNM, Unhas, UMI |
| **Desember** | Beberapa PTS, UKIP, UVRI |

**Pola musiman:** Ada gelombang wisuda hampir setiap bulan. Puncak di **Februari–Juni** (akhir TA gasal) dan **September–November** (akhir TA genap). Tidak ada bulan mati total.

**Implikasi bisnis:** Permintaan stabil sepanjang tahun dengan puncak di 2–3 bulan tertentu. Cocok untuk bisnis berkelanjutan, bukan musiman.

## 5. Insight Potensi Bisnis

### Kekuatan Pasar
1. **Volume tinggi:** 30.000–50.000+ wisudawan/tahun di Makassar
2. **Frekuensi tinggi:** Ada wisuda hampir setiap bulan → bisnis tidak mati musim
3. **Demografi muda:** Target pasar melek sosial media, mudah dijangkau digital
4. **Budaya foto:** "Wisuda wajib foto" — hampir 100% wisudawan menggunakan jasa foto
5. **Repeat purchase:** Alumni bisa jadi klien prewedding, wedding, family portrait

### Pain Points Konsumen (Peluang)

| Masalah | Peluang untuk Platform |
|---|---|
| **Bingung cari fotografer** | Directory/rekomendasi vendor terverifikasi |
| **Harga tidak transparan** | Price comparison fitur |
| **Kualitas tidak konsisten** | Rating & review system |
| **Booking ribet** | Booking online terintegrasi |
| **Foto lambat dikirim** | SLA guarantee |
| **Hasil editing mengecewakan** | Preview before final, editor quality check |

### Model Bisnis Potensial
1. **Marketplace / Platform Aggregator** — Hubungkan wisudawan dengan fotografer. Komisi per transaksi.
2. **Platform Booking + Price Comparison** — Daftar harga semua vendor, bandingkan, booking.
3. **Platform Portfolio** — Showcase hasil fotografer Makassar, lead generation.
4. **Bundle Layanan** — Foto + cetak + album + toga sewa dalam satu platform.

### Rekomendasi Strategi
- **Target early adopter:** Mahasiswa UNM, Unhas, UIN (volume besar, lokasi terpusat)
- **Pendekatan:** Kampus collaboration (event wisuda), influencer micro KOL mahasiswa
- **Revenue:** Komisi booking (10–20%), fitur premium listing, iklan
- **Differentiator:** Transparansi harga, kualitas terjaga, proses mudah
- **Timing:** Mulai promosi intensif 1 bulan sebelum musim wisuda puncak (Januari, April, Agustus)
